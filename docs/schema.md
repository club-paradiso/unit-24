# Schema reference

JSON Schema for every persisted model is generated by `scripts/export_schemas.py` into
`schemas/`. This page explains intent; the schema files are authoritative for shape.

## Agency (`Agency.schema.json`)

`agency_id` (deterministic: `agy_` + sha256(namespace, key)), `canonical_name`,
`alternate_names`, `agency_type` (25 values incl. `unknown` and
`task_force_or_reporting_unit`), `country`, `state` (validated; `ZZ` reserved for fixtures),
`county`, `municipality`, `jurisdiction_description`, `parent_agency`, `dispatch_provider`,
`official_website`, `official_contact_page`, `source_registry_ids` (registry → ids),
`status` (active/inactive/unknown), `valid_from`, `valid_to`, `first_seen`, `last_verified`,
`research_status` (registry_only, seed_unconfirmed, discovery_started, domain_discovered,
documents_discovered, documents_acquired, facts_extracted, no_public_source, blocked,
unknown), `is_fixture`, `notes`.

`None` means UNKNOWN for every optional field. `official_website` may only be set with a
recorded basis in `notes` (invariant `unknown_stays_unknown`).

## AgencyLink

Agency ↔ registry record relation: `link_kind` (identity | subunit | related), `status`
(confirmed | proposed | ambiguous | rejected), `basis` (rule + evidence), `score`,
`competing_agency_ids` for ambiguous cases.

## DocumentLead

A URL that might be evidence: host, title, snippet, `discovered_via`, query, rank,
`retrieved_at`, `lead_class` (official_homepage_candidate, official_radio_policy_candidate,
official_document_candidate, standards_body_document, secondary_lead, enthusiast_lead,
unrelated), `classification_basis`, `host_is_official` (True/False/None), `acquisition_status`
(pending, fetched, blocked_egress, robots_disallowed, http_error, network_error,
skipped_not_candidate, unsupported_content), `source_id` once acquired.

## Source (evidence object)

`source_id`, `source_type`, `title`, `issuing_authority`, `agency_or_jurisdiction`,
`canonical_url`, `original_file_url`, `retrieved_at`, `publication_date`, `effective_date`,
`revision`, `page_count`, `document_hash` (`sha256:…`), `local_path`, `content_type`,
`source_quality` (OFFICIAL_CURRENT, OFFICIAL_HISTORICAL, OFFICIAL_PARTIAL,
SECONDARY_CORROBORATED, CONFLICTING, UNVERIFIED, NO_PUBLIC_SOURCE), `temporal_status`
(current | historical | uncertain), `supersedes`, `superseded_by`, `is_fixture`, `notes`.

Validators: OFFICIAL_* requires a hash; search results are always UNVERIFIED; crowdsourced
and social sources can never be OFFICIAL_*.

## ProtocolFact

`fact_id`, `agency_id`, `fact_type`, `key` (normalized lookup key: `10-4`, `letter:A`,
`proc:readback`, `struct:vehicle_description`…), `value` (discriminated union below),
`raw_value`, `source_id`, `locator` (`p.12`, `html:table[1]>tr[7]`, `section 4.3`),
`excerpt` (≤400 chars), `effective_from`, `effective_to`, `temporal_status`, `supersedes`,
`superseded_by`, `confidence` (0–1), `verification_status` (verified, corroborated,
unverified, rejected), `extraction_method` (deterministic_parser, model, human,
registry_import), `extraction_model`, `review_status` (unreviewed, auto_accepted,
needs_review, human_accepted, human_rejected), `notes`, `created_at`, `run_id`.

Value kinds:

| kind | fields | covers |
|---|---|---|
| `code_meaning` | code_system (TEN_CODE, ELEVEN_CODE, SIGNAL, CODE, STATUS, DISPOSITION, OTHER), code, meaning, usage_note | A. codes and signals |
| `phonetic_letter` | letter, word, system (NATO, APCO_1941, LAPD_STYLE, LOCAL, UNKNOWN), context | B. phonetic systems incl. context-specific substitutions |
| `phonetic_system` | system, scope | B. which alphabet an agency uses |
| `callsign_convention` | element (unit, beat, rank, function, division, precinct), pattern, examples, description | C. unit/callsign conventions |
| `procedure_rule` | procedure (acknowledgement, radio_check, repeat_request, correction, readback, emergency_traffic, priority_traffic, clearing_call, traffic_stop, warrant_person_check, vehicle_plate, location_address, numeric), rule_text, prescribed_phrases | D. transmission procedure |
| `ordered_structure` | structure (vehicle_description, person_description, plate_readback, other), ordered_fields, mnemonic | E. ordered information |
| `interop_rule` | rule_kind (plain_language_required, mutual_aid, nims_ics, code_use_restriction, other), scope, rule_text | F. interoperability |
| `protocol_mode` | mode (ten_codes, plain_language, mixed, eleven_codes, signals, other), scope, statement | G. historical/current mode |

Historical variation (G) is carried by `effective_from/to`, `temporal_status`,
`supersedes/superseded_by` on both facts and sources.

## Conflict

`conflict_id`, `agency_id`, `fact_type`, `key`, `fact_ids` (all participants), `source_ids`,
`kind` (official_vs_official, current_vs_obsolete, agency_vs_dispatch, state_vs_municipal,
secondary_vs_official, secondary_vs_secondary, undated_manual, other), `resolution`
(unresolved, resolved_temporal, resolved_jurisdictional, resolved_quality, resolved_human),
`preferred_fact_id`, `rationale`.

## EligibilityDecision / TrainingItem

`subject_kind` (fact | agency), `subject_id`, `state` (PLAYABLE_VERIFIED,
PLAYABLE_WITH_LIMITATIONS, RESEARCH_ONLY, HISTORICAL_ONLY, CONFLICT_REQUIRES_REVIEW,
INSUFFICIENT_EVIDENCE), `reasons`, `supporting_source_ids`, `conflict_ids`, `policy_version`.

`TrainingItem` (future app) requires non-empty `fact_ids` and `source_ids`;
`radiocorpus explain <fact_id>` shows exactly what such an item would cite.

## Eligibility policy (policy_version 2026-09-20.1)

| condition | verification | eligibility |
|---|---|---|
| rejected by validation or human | as is | INSUFFICIENT_EVIDENCE |
| participates in an unresolved conflict | UNVERIFIED | CONFLICT_REQUIRES_REVIEW |
| model-extracted, not human-accepted | UNVERIFIED | RESEARCH_ONLY |
| contradicted by preferred source (quality/jurisdiction resolution) | UNVERIFIED | RESEARCH_ONLY |
| superseded (temporal resolution) or historical source | VERIFIED (if official) | HISTORICAL_ONLY |
| source OFFICIAL_CURRENT | VERIFIED | PLAYABLE_VERIFIED |
| source OFFICIAL_PARTIAL | VERIFIED | PLAYABLE_WITH_LIMITATIONS |
| same value in ≥2 independent non-official sources | CORROBORATED | PLAYABLE_WITH_LIMITATIONS |
| otherwise | UNVERIFIED | RESEARCH_ONLY |

Agency eligibility is the best state among its facts, else INSUFFICIENT_EVIDENCE.

## Invariants (`invariants.py`)

1. No PLAYABLE_VERIFIED fact without an OFFICIAL_CURRENT, hashed source.
2. No fact cites a source attributed to a different agency (unless that agency is its
   documented parent or dispatch provider) — no neighbour synthesis.
3. No historical source yields a PLAYABLE_VERIFIED fact; temporal resolutions prefer the newer date.
4. No model output is VERIFIED without human acceptance; no VERIFIED fact lacks an excerpt.
5. Every fact referenced by a conflict still exists.
6. `official_website` only with a recorded basis; REGISTRY_ONLY agencies carry no researched fields.
7. Official quality only for hashed documents; never for crowdsourced/social/search sources.
8. Every fact has a locator and a resolvable source.
